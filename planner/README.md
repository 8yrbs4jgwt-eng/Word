# Мой планировщик

Личный сайт-помощник: «Мой день», календарь, задачи, заметки, почта Mail.ru (только чтение) и ИИ-помощник.
Данные хранятся в файле `data/planner.db` на вашем компьютере.

## Запуск
Нужен Node.js 22.13 или новее (nodejs.org).

```
cd planner
npm install
npm start
```
Откройте http://localhost:3000. Первый открывший сайт создаёт свой аккаунт (email + пароль от 10 символов);
после этого регистрация закрыта (чтобы разрешить ещё один аккаунт: `ALLOW_REGISTRATION=1`).
Кнопка «Открыть демо» показывает тестовые данные в отдельном аккаунте — они не смешиваются с вашими (отключить: `ALLOW_DEMO=0`).

Настройки (необязательно): скопируйте `.env.example` в `.env`.

## Почта Mail.ru
Используется официальный способ: IMAP `imap.mail.ru:993` + «пароль для внешнего приложения»
(id.mail.ru/security → Пароли для внешних приложений → доступ «Протокол IMAP»). Обычный пароль не подойдёт.
Письма читаются в режиме «только чтение»; сайт ничего не отправляет, не удаляет и не помечает прочитанным.
Внимание: с 2026 года Mail.ru тестирует платный доступ по IMAP (подписка «Пространство Mail») — на части ящиков вход может отклоняться.
Отключение в разделе «Почта» удаляет сохранённый пароль.

## ИИ-помощник
Нужен отдельный API-ключ Anthropic (console.anthropic.com), оплата по использованию, отдельно от подписки Claude.
Ключ вводится в «Настройки» (хранится на сервере зашифрованным) или в `.env` (`ANTHROPIC_API_KEY`). Без ключа чат показывает «ИИ не подключён», остальное работает.
Все изменения помощник только предлагает — применяются кнопкой «Применить», последнюю операцию можно отменить.
Письма передаются модели только после вашего согласия и только в запросах с включённым переключателем.

## Проверка
`npm test` — автотесты сервера (доступ, повторы событий, пересечения, дедупликация писем, ИИ с подтверждением).

## Размещение в интернете (по желанию)
Сейчас сайт слушает только `127.0.0.1` (виден лишь вам). Для доступа с телефона/из интернета нужен хостинг с постоянным диском
(VPS, Fly.io, Railway и т.п.), HTTPS и `COOKIE_SECURE=1`. Не открывайте сайт в интернет без HTTPS.
Резервная копия — файлы папки `data/` (`planner.db` и `secret.key`; без `secret.key` сохранённые пароли не расшифровать).

## Публикация на Render.com (с iPad)
Файлы `render.yaml` и `Dockerfile` уже готовы. Render → New → Blueprint → выбрать репозиторий и ветку → задать `SETUP_CODE` (секретный код для регистрации) → Apply.
Тариф Starter (платный) нужен ради постоянного диска с базой. После запуска сразу создайте свой аккаунт с этим кодом.

## Устройство
`server/` — сервер (Express, SQLite из Node, imapflow), `public/` — страница без сборки, `test/` — тесты.
